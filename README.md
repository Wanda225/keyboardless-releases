# 鍵談 Keyboardless

不用鍵盤，依然鍵談。按一下快捷鍵、開口說話，整理好的台灣繁體中文就會出現在游標所在的位置。

這裡只放安裝檔。適用 Apple Silicon 的 Mac。

## 下載與安裝

1. 到 [Releases](https://github.com/Wanda225/keyboardless-releases/releases/latest) 下載最新的 `.dmg`。
2. 打開後，把「Keyboardless」拖到「Applications」（應用程式）資料夾。
3. 第一次打開時，macOS 會顯示「無法打開，因為 Apple 無法檢查是否含有惡意軟體」，這是因為 Beta 版還沒有經過 Apple 的公證。請按「完成」，再到「系統設定 › 隱私權與安全性」往下捲到「安全性」，按「強制打開」。只需要做這一次。
4. 照著畫面允許權限、貼上你自己的 AI 服務金鑰，就可以開始用了。

已經安裝的人不用重新下載：在鍵談的「設定 › 一般」按「檢查更新」即可。

## 關於 Beta 版

鍵談還在 Beta 階段，目前的 Beta 版可以使用到 2027 年 4 月 7 日，之後請更新到新版本。歡迎分享給需要的人，也歡迎告訴我哪裡可以更好（鍵談側邊欄的「意見回饋」）。

請只從這個頁面下載安裝檔。每個版本都附有 `SHA256SUMS.txt`，可以用來確認檔案沒有被更動。
